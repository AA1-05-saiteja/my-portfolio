## 💻 How to Run Locally

You can open `index.html` directly in any web browser, or launch a local web server:

```bash
# Using Python 3
python -m http.server 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)

---

## 🌐 Deploy to GitHub Pages

1. Ensure the project is pushed to the `main` branch of `https://github.com/AA1-05-saiteja/my-portfolio`.
2. On GitHub, navigate to **Settings** → **Pages**.
3. Under **Branch**, select `main` and set the folder to `/ (root)`.
4. Click **Save**. Your portfolio will be live at: `https://aa1-05-saiteja.github.io/my-portfolio/`.
